# Hospital Management System

## Software Requirements Specification Report

This repository contains the **Software Requirements Specification (SRS) Report** for the Hospital Management System.

### Report Contents

The report covers:

- Introduction
- Objectives
- Scope of the System
- Stakeholders and User Roles
- Functional Requirements
- Non-Functional Requirements
- User Requirements
- System Requirements
- Technical Requirements
- Major System Modules
- System Workflow
- Major Data Entities
- Security and Privacy Requirements
- Reporting and Analytics
- Expected Benefits
- Future Enhancements
- Conclusion

### Domain

**Healthcare / Hospital Management**

### Purpose

The purpose of this report is to define and document the requirements of a Hospital Management System, including its functional, non-functional, user, system, and technical requirements.
